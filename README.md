# Roshan Prajapati – Portfolio
Vite + React + TypeScript + Tailwind + Framer Motion + Lucide.
- `npm install && npm run dev` to run locally, `npm run build` to build.
- Edit experience and case-study content in `src/data.ts`; other copy is in `src/components/`.
- Replace the resume by overwriting `public/Roshan_Prajapati_Resume.pdf`.
- Deploy: push to GitHub, import the repo at vercel.com/new (Vite is auto-detected). Every push to `main` redeploys.
